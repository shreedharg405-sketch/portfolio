# Developer Portfolio — SHREEDHAR G

Modern, responsive static developer portfolio website for **SHREEDHAR G**, tailored for hosting on **GitHub Pages**.

## Architecture & Structure
- `index.html` - Single-page root application (Hero, About, Education, Experience, Skills, Projects, Certificates, Contact)
- `css/` - Custom CSS design system
- `docs/` - Project documentation
- `html/` - Static HTML redirect files (`about.html`, `projects.html`, `contact.html`)
- `js/` - Interactive JavaScript modules (Theme switcher, Canvas Particles, Typing effect, Scroll animations, Contact form)
- `uploads/` - Profile images, project media, certificates, and resume PDF

## GitHub Pages Deployment
1. Upload/push repository contents to `https://github.com/shreedharg405-sketch/Protfolio.git`.
2. Enable GitHub Pages under **Settings -> Pages -> Source: Deploy from branch (main / root)**.
3. Site will be live at `https://shreedharg405-sketch.github.io/Protfolio/`.
